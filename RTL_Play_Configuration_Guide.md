
# Guide de Configuration RTL Play

## Problème
Les chaînes RTL (RTL-TVI, Club RTL, Plug RTL) exigent maintenant une authentification obligatoire.

## Solution

### 1. Créer un compte RTL Play (gratuit)
- Visitez https://www.rtlplay.be
- Cliquez sur "S'inscrire" ou "Créer un compte"
- Remplissez le formulaire d'inscription
- Confirmez votre email

### 2. Configurer l'addon
1. Ouvrez les paramètres de l'addon Catch-up TV & More
2. Naviguez vers "Chaînes belges" → "RTL Play"
3. Entrez votre nom d'utilisateur/email RTL Play
4. Entrez votre mot de passe RTL Play
5. Sauvegardez les paramètres

### 3. Redémarrer
- Redémarrez l'addon ou Kodi
- Les chaînes RTL devraient maintenant fonctionner

## Messages d'erreur courants

### "RTL Play authentication required"
→ Vous devez configurer vos identifiants dans les paramètres

### "Invalid credentials"  
→ Vérifiez votre nom d'utilisateur et mot de passe

### "SSO authentication failed"
→ Problème temporaire, réessayez plus tard

## Chaînes concernées
- RTL-TVI (principale chaîne belge francophone)
- Club RTL  
- Plug RTL
- RTL Info
- BEL RTL

## Support
Si les problèmes persistent après configuration:
1. Vérifiez que vos identifiants fonctionnent sur rtlplay.be
2. Redémarrez complètement Kodi
3. Signaler le problème sur GitHub avec les logs
